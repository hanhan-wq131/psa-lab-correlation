# 攝護腺癌個案 PSA × 血液檢驗關聯分析工具

一個純網頁（單一 HTML 檔）的分析工具：上傳「檢驗數值 Excel」與「個案確診攝護腺癌時間點 Excel」，即可自動計算 **PSA 與血糖、血脂、紅血球／白血球等血液檢驗數值的關聯性**，並產生互動式統計圖表。

🔒 **隱私**：所有 Excel 檔案只在使用者自己的瀏覽器內解析與計算，**不會上傳到任何伺服器**。

## 使用方式

1. 開啟網頁：建議使用 GitHub Pages 連結；離線使用時請下載**整個資料夾**（`index.html` 必須與 `vendor/` 資料夾放在一起），再用 Chrome 或 Edge 開啟 `index.html`。不需要網路連線。
2. 上傳 **檢驗數值 Excel**（例：`RCGRDLABRSLT檢驗結果歷史檔.xlsx`）。
3. 上傳 **確診時間點 Excel**（例：`攝護腺癌個案確診日期_門診急診合併.xlsx`）。
4. 自動產生結果；可調整分析設定，結果會即時更新。

## 檔案格式

**檢驗數值檔**（欄位名稱會自動偵測，也可手動對應）

| 欄位 | 預設欄 | 說明 |
|---|---|---|
| 條碼編號 | C | 個案編號，需與確診檔一致 |
| 檢體 | G | **B = 血液（分析）**；血液以外的檢體（如 U = 尿液）不納入分析 |
| 檢驗名稱縮寫 | I | 例如 PSA、Glucose(AC)、WBC、T-Cholesterol |
| 輸入日期 | J | YYYYMMDD、Excel 日期、民國日期皆可 |
| 檢驗結果值 | L | `<0.008` 等低於偵測下限以下限值計；eGFR `>60( 64 僅供參考)` 取括號內數值；Negative 等文字結果略過 |
| 檢驗值單位 | T | 選填 |

**確診時間點檔**：需有「條碼編號」與「首次確診攝護腺癌日期」。若有多個工作表，會自動選擇含「確診」欄位的工作表（可手動切換）。

## 分析內容

- **相關係數長條圖**：每項血液檢驗與 PSA 的 Spearman ρ，可依類別（血糖、血脂、血球、肝功能、腎功能、電解質、荷爾蒙…）篩選。
- **統計結果表**：配對數、個案數、Spearman ρ、p 值、FDR 校正 q 值、log(PSA) Pearson r，可下載 CSV。
- **散佈圖**：PSA（對數座標）vs. 所選檢驗，含趨勢線。
- **依 PSA 分組箱型圖**：PSA < 4、4–10、10–20、≥ 20 ng/mL 各組的檢驗值分布。
- **相對確診時間趨勢**：以確診日為 0，每 3 個月的中位數與四分位距。
- **個案檢視**：單一個案的 PSA 與所選檢驗隨時間變化。
- **自動解讀摘要**：以文字列出顯著正／負相關的項目與注意事項。

## 方法說明

- **配對**：每一筆 PSA 檢驗，找同一個案在 ±N 天（預設 7 天）內最接近的另一項檢驗結果配成一對。
- **分析期間**：全部、確診前、確診後、確診前後一年或自訂（以 PSA 檢驗日相對確診日計算）。
- **分析單位**：「每次配對」使用所有配對；「每位個案一點」將同一個案的配對取中位數，避免重複測量造成的偏差。
- **統計**：Spearman 等級相關（主要指標，對 PSA 偏態分布較穩健）與 log10(PSA) 的 Pearson 相關；p 值以 t 分布計算；以 Benjamini–Hochberg 法做多重比較校正。

## 注意事項

本工具僅供研究探索使用，相關不代表因果。PSA 及部分檢驗（如 Testosterone）會受治療（例如荷爾蒙治療）影響，解讀時請一併考量臨床背景。

## 技術

單一靜態 HTML 檔，使用 [SheetJS](https://sheetjs.com/)（xlsx 0.18.5）解析 Excel、[Plotly.js](https://plotly.com/javascript/)（2.35.2）繪圖；兩者已放在 `vendor/` 資料夾內，不依賴外部 CDN，無需安裝或後端伺服器。
